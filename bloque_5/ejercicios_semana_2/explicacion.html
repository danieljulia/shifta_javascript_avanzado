Ejemplos de Vue.js – Semana 2

Resumen de lo que hace cada ejemplo de esta carpeta y cómo ejecutarlo. Los ejemplos CDN se abren directamente en el navegador (los que usan fetch necesitan un servidor, por ejemplo Live Server o vite). Los ejemplos Vite necesitan npm install y npm run dev.

Primeros pasos

1_vue_sencillo CDN

Primer contacto con Vue 3 cargado desde un CDN.

  • index.html: un contador y una lista de tareas (añadir con Enter, marcar como completadas).
  • index_vue_version_3.html / index_vue_version_2.html: el mismo contador en Vue 3 y en Vue 2 para comparar la sintaxis.

Conceptos: interpolación {{ }}, @click, v-model, v-for, v-if, :style.

ejemplos_vue_sencillos_vue3_cdn CDN

Cinco mini aplicaciones, cada una centrada en una idea:

  • contador.html: botones para sumar y restar.
  • contador_visitas.html: cuenta las visitas y las guarda en localStorage.
  • reloj.html: reloj digital que se actualiza cada segundo y limpia el temporizador al cerrarse.
  • modal.html: ventana modal que se abre y se cierra (X, botón, fondo o tecla Escape).
  • imagenes_aleatorias.html: muestra una imagen aleatoria cada vez que se pulsa el botón.

Conceptos: métodos, hooks created y beforeUnmount, v-if / v-else, :src.

Proyectos con Vite

2_vue_vite Vite

El mismo contador, pero como proyecto con Vite y el paquete npm de Vue. Muestra la estructura mínima: index.html, app.js (crea y monta la app), App.vue (componente) y vite.config.js.

Conceptos: componente de un solo archivo (template + script + style scoped), npm run dev y npm run build.

3_portfolio Vite

Portfolio de un artista. Lee public/data.json con fetch y muestra el nombre, la biografía, la galería de proyectos y los datos de contacto. Incluye un menú tipo hamburguesa.

Conceptos: fetch en mounted, v-for con :key única, v-if mientras llegan los datos, base: './' en vite.config.js.

4_portfolio_componentes Vite

Portfolio dividido en componentes: Menu, Content y ProjectCard. La página de inicio lista los proyectos de public/data/projects.json; con ?id=1 en la URL se muestra el detalle de un proyecto.

Conceptos: componentes, props, computed, URLSearchParams, <script setup> en App.vue.

API externa y varias páginas

5_explorador_pokemon CDN

Buscador de Pokémon por nombre o número usando PokeAPI. Muestra imagen, tipos y estadísticas, y avisa si no se encuentra.

  • index.html: versión básica.
  • index_v2.html: añade estado de carga, botones anterior / siguiente y habilidades.

Conceptos: Composition API (ref, computed, setup), async/await, comprobar res.ok, gestión de errores.

6_vue-simple-cdn-multipage CDN

Portfolio de tres páginas (inicio, proyectos y sobre mí) sin Node ni compilación. La cabecera y el pie están definidos una vez en js/app.js y se reutilizan; los proyectos se cargan de data/data.json.

Conceptos: componentes compartidos entre páginas, plantillas <template id="...">, fetch compartido mediante una promesa.

Componentes avanzados y estado global

7_gestor_tareas Vite

Gestor de tareas: añadir, marcar como completadas, eliminar y filtrar (todas / pendientes / completadas), con estadísticas. Las tareas se guardan en localStorage.

Componentes: TaskForm, TaskFilters, TaskItem y TaskStats.

Conceptos: props hacia abajo y eventos ($emit) hacia arriba, computed, watch con deep: true, @submit.prevent.

8_pinia_global Vite

Dos componentes independientes (CounterPanel y MessagePanel) que comparten el mismo estado: un contador y un mensaje editable, guardados en un store de Pinia.

Conceptos: defineStore (state y actions), createPinia() en main.js, uso del store con setup().

Cómo ejecutar los ejemplos

  • CDN: abrir el .html en el navegador, o con Live Server / vite si usa fetch.
  • Vite: dentro de la carpeta, npm install y después npm run dev. Para producción: npm run build (se genera dist).
