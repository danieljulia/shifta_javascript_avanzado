# 1_vue_sencillo

Ejemplos de Vue cargando la librería desde un CDN (sin instalar ni compilar nada).

- `index.html`: contador y lista de tareas (interpolación, `v-model`, `v-for`, `v-if`, eventos)
- `index_vue_version_3.html`: contador mínimo con Vue 3
- `index_vue_version_2.html`: el mismo contador con Vue 2, para comparar la sintaxis

## Cómo ejecutarlo

- Abrir el `.html` directamente en el navegador, o
- usar la opción "Open with Live Server" de Visual Studio Code, o
- desde este directorio, con Vite instalado globalmente:

```bash
npm install -g vite
vite
```
